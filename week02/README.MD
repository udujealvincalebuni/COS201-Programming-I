## Week 2: Development Environment and First Java Program

### Practical Title
Development Environment and First Java Program

### Objective
To configure the Java development environment, write a simple
Java program, compile it, execute it and submit the source code
through GitHub.

### Tools Used
- Java Development Kit (JDK)
- Visual Studio Code
- Git
- GitHub Desktop
- GitHub

### Files
- `week02/HelloWorld.java`: Java source code for the practical.
- `week02/PrintExample.java`: practice exercise on `print()` and `println()`.
- `week02/ErrorExample.java`: debugging exercise (missing semicolon corrected).

### How to Run
1. Open a terminal in the `week02` directory.
2. Compile the program using `javac HelloWorld.java`.
3. Run the program using `java HelloWorld`.

### Learning Outcome
I practised creating, compiling and running a Java program and submitting source code through GitHub, then sending the repository link through the Google Form provided by the lecturer.
